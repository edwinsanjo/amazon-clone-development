# Amazon Clone

this is one of my favorite project becaus this app uses one of my favorite library flutter this is a bit big and lenght project a amazon clone with a mongodb backed and admin pannel this code is based on a video by free code camp and ive done so many improvements and made it 100% better guarantee

## Features

- Uses flutter (mobile, desktop, web)
- uses mongodb (scalability)
- better design than amazon
- apple pay and google pay
- cart and rating functionality
- getting deal of the day
- Product filtering and searching
- Admin Panel
  - add, delete and edit products
  - viewing orders and editing status of devlivery
  - viewing earnings as text and graphs

## Installation

Install my-project with

```bash
  git clone https://github.com/RivaanRanawat/flutter-amazon-clone-tutorial.git
  cd flutter-amazon-clon-tutorial
```

Now lets setup the server

```bash
  cd server
  npm install
```

to run the server

```bash
  # for development
  npm run dev
      or
  #for one time run
  npm run start
```

to run the client. In another terminal type

```bash
  flutter run
```
